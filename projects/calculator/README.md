# Local C++ Calculator

A lightweight calculator with a C++ HTTP server and an HTML/CSS user interface.

## Features

- C++ backend for arithmetic evaluation
- HTML/CSS calculator UI with a polished local-only layout
- Keyboard support and button clicks
- Serves from `http://localhost:8080`

## Build

```bash
make
```

## Run

```bash
make run
```

Then open:

```text
http://localhost:8080
```

## Supported expressions

- Addition, subtraction, multiplication, and division
- Parentheses
- Decimal numbers
- Unary plus and minus
